# Rx Scan Editor — Android project

এই প্রকল্পটি Android Studio-তে খোলার জন্য তৈরি করা হয়েছে।

## কী করতে পারে
- গ্যালারি থেকে প্রেসক্রিপশনের ছবি নির্বাচন
- Google ML Kit Latin OCR দিয়ে ছবি থেকে লেখা শনাক্ত
- শনাক্ত করা লেখা অ্যাপের ভেতরে সম্পাদনা
- সম্পাদিত টেক্সটকে PDF ট্রান্সক্রিপশন হিসেবে সংরক্ষণ

## সীমাবদ্ধতা
- এই সংস্করণের OCR মূলত ইংরেজি/Latin অক্ষরের জন্য। বাংলা হাতের লেখা নির্ভরযোগ্যভাবে শনাক্ত নাও হতে পারে।
- ওষুধের নাম, শক্তি, ডোজ ও নির্দেশনা OCR ভুল করতে পারে; চিকিৎসকের সঙ্গে মিলিয়ে নিন।
- PDF-টি একটি টেক্সট ট্রান্সক্রিপশন, আসল প্রেসক্রিপশন নয়। এটি মূল ছবি, চিকিৎসকের স্বাক্ষর বা সিল পরিবর্তন করে না।

## APK বানানোর নিয়ম
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. Android Studio থেকে `Open` নির্বাচন করে এই ফোল্ডারটি খুলুন।
3. Gradle sync সম্পন্ন হতে দিন; প্রয়োজনে Android SDK 35 ইনস্টল করুন।
4. `Build > Build Bundle(s) / APK(s) > Build APK(s)` নির্বাচন করুন।
5. APK সাধারণত `app/build/outputs/apk/debug/app-debug.apk`-এ পাওয়া যাবে।

এই পরিবেশে Android SDK/Gradle build tools নেই, তাই এখানে সরাসরি APK কম্পাইল করা হয়নি।
